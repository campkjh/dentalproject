## 미해결: 실제 안드로이드 사진 업로드

사용자가 Galaxy S22에서 새 버전으로 다시 시도했으나 사진이 올라가지 않는다고 확인했다. **실제 사용자 사진 업로드 문제는 해결 완료 상태가 아니다.**

- 로컬 브라우저에서 실제 컴포넌트의 선택 즉시 업로드 핸들러 호출을 확인했다. 이 검증은 모의 업로드로 진행했다.
- 기기에서 작은 테스트 JPG의 업로드 완료 화면을 관찰했지만 사용자 사진의 실패 원인을 설명하지 못한다.
- Android Studio 미러링 화면이 멈춘 구간이 있었으므로 해당 구간의 클릭과 화면 관찰은 신뢰할 수 있는 재현·성공 검증으로 취급하지 않는다.
- 이 작업에서 Android 네이티브 사진 선택 코드의 수정·새 APK 설치는 아직 하지 않았다.

다음 작업은 최신 실기기 화면과 로그를 확보하고, Android `MainActivity`의 `onShowFileChooser` → Activity Result → `ValueCallback` → 웹 파일 선택 이벤트 전달을 확인하는 것이다. 이후 실제 사진의 미리보기·업로드·저장까지 검증해야 한다. 기존 운영 상품을 임의로 생성·삭제하지 않는다.
